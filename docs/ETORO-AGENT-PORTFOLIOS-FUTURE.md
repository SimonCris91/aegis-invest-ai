# eToro Agent Portfolios: Future Research

Agent Portfolios remain outside the executable Step 5 scope. Current official
documentation exposes dedicated Agent Portfolio operations and scopes, with
deprecated versions listed separately. A future phase must re-verify the
current documentation and permissions before adding any call.

No Agent Portfolio endpoint, token, or scope is implemented here. Adoption
requires a separate review of custody, user consent, portfolio isolation,
reconciliation, incident response, and app-review requirements.
